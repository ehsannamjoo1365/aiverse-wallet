# Security Policy

## Current security status

AIVerse Wallet is currently a demonstration interface only. It is not suitable for storing, receiving, or sending real cryptocurrency.

## Do not submit secrets

Never create issues or pull requests containing private keys, seed phrases, wallet backups, passwords, API tokens, or personal financial information.

## Reporting a vulnerability

Please do not publish exploitable vulnerability details in a public issue. Contact the repository owner privately through GitHub's private vulnerability reporting feature if it is enabled, or use a private communication channel.

## Release requirement

No release should be described as safe for real funds until the wallet's cryptographic design, key lifecycle, signing flow, transaction construction, network integrations, recovery process, and threat model have been independently reviewed and tested.
